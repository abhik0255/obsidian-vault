# Claude Memory Index

This folder contains all memories from Claude Code conversations.

## Structure

- [[Chat History|chat-history/]] - Past conversation summaries
- [[Projects|projects/]] - Project-specific information

## How Claude Uses This

- Claude reads these files at the start of each session
- Use `[[links]]` to connect related memories
- Add metadata in YAML frontmatter for better organization

## Quick Start

When starting a new conversation, Claude will:
1. Scan this index
2. Review relevant memories
3. Continue from where we left off
